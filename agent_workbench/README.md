# Agent Workbench (catbalony experimental)

External-agent orchestration area for the **catbalony** GeneWars
reverse-engineering fork. This is NOT part of the upstream
`mefistotelis/genewars-re-helpers` project and carries no upstream
authority.

Scope statement:

- **catbalony-specific experimental AI orchestration.** Batches here
  coordinate disposable external research agents (LMArena, Grok,
  DeepSeek, GLM, ...).
- **Not canonical GeneWars proof.** External worker output is research
  material only. It is never proof authority; nothing external is
  automatically promoted to any canonical status. Only deterministic
  verification performed by the project itself can establish PROVEN
  results, and those live in the private repo, not here.
- **Public material only.** Everything published under this folder is
  generated by a fail-closed packer from an allowlist of fields. Private
  repo paths, binaries, savestates, canon dumps and secrets are excluded
  by construction. If you find anything that looks private, it is a bug -
  please report it.
- The public symbols/XML/bytes already in this repository remain the
  shared reference surface; batches here reference them by name rather
  than duplicating them.

agent to start.
